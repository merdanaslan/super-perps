The GIF is a 10-second loop made from four unaltered screenshot views, held for
2.5 seconds each. It is a screen-by-screen tour, not a continuous interaction
recording. Only image encoding/compression was applied. It is collapsed by
default in the README so readers can choose whether to view the animation.

These are actual local-browser screenshots, without a connected user account,
wallet address or fabricated portfolio. Prices are snapshots. They are neither
physical-device captures nor evidence of trade execution. Source artwork and
third-party mark provenance are in [brand assets](../brand-assets.md).

Other files in this directory are historical UI/verification captures. Some
show earlier designs or features since removed. `chart-position-fixture.jpg`
is explicitly a sample-data rendering check, not a funded position. Consult the
linked dated verification record before using an older image as current evidence.

When refreshing the README, capture the current app in an anonymous session,
keep all images and GIF frames at the same viewport, check them for private data, and
update this date. Do not change market values or make a mock balance look real.
